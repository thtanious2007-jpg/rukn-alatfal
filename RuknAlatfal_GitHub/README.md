# رُكن الأطفال 🐱📚

منصة إلكترونية تفاعلية للأطفال ذوي الإعاقة العقلية (مشروع تخرّج، كلية علوم ذوي الاحتياجات الخاصة، جامعة الزقازيق).
تحت إشراف الدكتورة / إيمان الكاشف.

- ألعاب تعليمية وحكايات مع أسئلة فهم وركن للرسم
- ركن الأغاني، وركن الهدوء، وجدول «أولًا ثم»، وهدايا بالنجوم
- أدوات قراءة وإتاحة (حجم الخط، سرعة الصوت، تباين عالٍ، وضع الهدوء)
- تطبيق ويب قابل للتثبيت (PWA) ويعمل دون إنترنت بعد أول فتح

## التشغيل
الموقع ملفات ثابتة بدون خادم. للنشر على GitHub Pages: Settings ← Pages ← Deploy from a branch ← main ← / (root).

## الخصوصية
التقدم محفوظ على جهاز الطفل فقط، ولا تُرسل أي بيانات لأي خادم.
